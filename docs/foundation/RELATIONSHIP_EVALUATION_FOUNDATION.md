# 婚恋评价系统：基础坐标系

**Status:** Research draft v0.1.1  
**Scope:** Human relationship / attraction research foundation  
**Nature:** 研究框架，不是对 Human 当前状态的事实断言

> Migration provenance: migrated from `youling/an` PR #15, branch `human/relationship-evaluation-foundation-v0.1`, original blob `f7d95b6192b8a53b46905c4a67998ff1d3ca7896`. The prior artifact is retained as historical evidence; `youling/lhrm` is now the dedicated project home.

## 0. 目标

本文件只解决一个基础问题：

> 在研究吸引、恋爱、婚姻、角色适配、关系稳定、婚恋市场与社会环境之前，先固定一套足够精妙、优雅、直接且可扩展的底层坐标系。

当前阶段不试图定义一个总的“喜欢函数”，也不追求 LoveScore。

设计原则：

1. **少而稳定**：底层大类尽量少，后续新增变量不应迫使重构坐标系。
2. **事实优先**：底层输入尽量描述事实或状态，不提前塞入“漂亮、贤惠、高价值”等高层结论。
3. **有序展开**：研究与评价按 `S → O → D → E` 展开；后层不能假定一定存在。
4. **角色与状态分离**：同一组已存在的底层状态可以被不同评价任务反复调用。
5. **动态但不漂移**：人、对象、关系与环境可以持续变化，基础结构本身尽量不变。

## 1. 四类底层变量，以及固定的展开顺序

四类变量固定为：

```text
S → O → D → E
主体 → 客体 → 二人 → 环境
```

这里的顺序不是排版习惯，而是研究流程中的**阶段结构**：

```text
Stage 1: S
Stage 2: (S, O)
Stage 3: (S, O, D)
Stage 4: (S, O, D, E)
```

因此更基础的状态表示不是一开始就假设四项齐全，而是逐层展开：

```text
X¹_t = S_t
X²_t = (S_t, O_t)
X³_t = (S_t, O_t, D_t)
X⁴_t = (S_t, O_t, D_t, E_t)
```

含义：

- 没有主体，就没有评价问题；
- 主体遇到一个具体对象以后，才有主体—客体评价；
- 两个人未发生足够互动时，不能假定存在成熟的二人变量 `D`；
- 二人关系尚未形成或尚未进入稳定、持续的关系考察时，不应提前把完整的外部环境适配 `E` 当成主要评价层。

**重要区分：** 外部世界当然从一开始就客观存在，也可能通过地点、文化、婚恋市场等间接影响前面的阶段；这里所说的 `E` 排第四，指的是把“二人放入现实社会环境后能否成立、维持与演化”作为一个**独立评价层**。不要把“世界存在”与“什么时候需要显式调用环境评价”混为一谈。

### 1.1 `S` — Subject / 主体：我

描述评价者自身。

可包含：

- 生理状态：年龄、健康、性欲等；
- 审美偏好；
- 心理与情绪状态；
- 价值观；
- 人生目标；
- 能力与资源；
- 当前需求；
- 过去经历形成的偏好与约束。

示例：

> “她腿长”不是 `S`；“俺特别吃腿这一项”属于 `S`。

### 1.2 `O` — Object / Other / 客体：她

描述被评价者自身，不掺入主体评价。

可包含：

- 外貌与身体；
- 年龄与健康；
- 性格；
- 智力与能力；
- 行为习惯；
- 收入与资源；
- 家庭背景；
- 价值观；
- 生育意愿；
- 穿着打扮；
- 当下精气神与精神状态。

示例：

> “她今天皮肤状态很好”属于 `O`；“她的皮肤很吸引俺”不是纯 `O`，而是主体与客体共同进入某个吸引函数后的结果。

### 1.3 `D` — Dyad / 二人系统：我们

描述只有把两个人放在一起、并发生互动以后才存在的关系变量。

可包含：

- 性化学反应；
- 聊天与互动节奏；
- 幽默是否互相接得住；
- 信任；
- 共同记忆；
- 冲突模式；
- 权力关系；
- 性契合；
- 双方投入；
- 长期相处形成的特殊习惯与默契。

示例：

> “她幽默”属于 `O`；“俺喜欢幽默的人”属于 `S`；“俺俩特别能接住对方的梗”属于 `D`。

`D` 不是简单的 `S + O`，而是耦合后的涌现项：

```text
D = g(S, O, interaction history)
```

因此不能仅凭双方资料把 `D` 当成已知变量；它需要互动后观测。

### 1.4 `E` — Environment / 环境：二人进入世界

`E` 描述已经形成的二人系统放入现实环境以后面对的外部条件、约束与机会。

可包含：

- 家庭与双方父母；
- 城市与地域；
- 工作地点与迁移成本；
- 收入环境、房价与就业；
- 社会网络；
- 婚恋与婚姻制度；
- 文化、性别与家庭规范；
- 生育政策与教育制度；
- 社会阶层；
- 宏观经济、战争与技术环境。

同样的 `S + O + D`，在不同 `E` 下可能形成完全不同的长期关系结果。

## 2. 两个不进入底层变量分类的坐标

### 2.1 `t` — 时间：状态索引

时间不作为第五类变量。

它只表示当前已经进入研究的各类变量在某个时刻的状态：

```text
S_t
(S_t, O_t)
(S_t, O_t, D_t)
(S_t, O_t, D_t, E_t)
```

主体在变、客体在变、二人系统在变、环境在变，但坐标系不必改变。

### 2.2 `ρ` — Role / Task：评价镜头

角色不是底层变量，而是当前评价任务。

示例：

```text
ρ = 视觉吸引
ρ = 性吸引
ρ = 恋爱伴侣
ρ = 妻子
ρ = 共同育儿者
```

同一组已观测状态，换一个 `ρ`，可以得到完全不同的评价结果。

## 3. 统一函数接口

所有后续研究函数共享同一原则，但只调用当前阶段已经成立的变量：

```text
Stage 1: Y_k(t) = F_k(S_t ; ρ)
Stage 2: Y_k(t) = F_k(S_t, O_t ; ρ)
Stage 3: Y_k(t) = F_k(S_t, O_t, D_t ; ρ)
Stage 4: Y_k(t) = F_k(S_t, O_t, D_t, E_t ; ρ)
```

完整状态可以简写为：

```text
X_t = (S_t, O_t, D_t, E_t)
Y_k(t) = F_k(X_t ; ρ)
```

但这个简写不能掩盖前面的阶段门控：`D`、`E` 在尚未成立时不能用想象值补齐。

不预设一个总的“喜欢”分数。

优先研究一组相互独立、可观测、可验证的函数，例如：

```text
F_visual       视觉审美 / 视觉吸引
F_sexual       性吸引
F_interaction  互动愉悦
F_chemistry    化学反应
F_trust        信任
F_role         角色适配
F_stability    关系稳定
```

未来如有必要，总体喜欢、承诺或婚姻选择，只作为这些基础函数之上的消费者，而不是底层公理。

## 4. 建模纪律

### 4.1 输入尽量描述事实，不偷塞结论

以下词默认视为高层输出或待拆概念：

- 漂亮；
- 贤惠；
- 有魅力；
- 有化学反应；
- 适合当老婆；
- 优质男性；
- 高价值女性。

例如不应写：

```text
婚姻适配 = 0.3 × 贤惠 + ...
```

因为“贤惠”本身已经把大量待解释的关系、责任与角色判断折叠进去了。

更好的做法是继续拆成更底层的、可观察的状态与行为，再由 `F_role` 等高层函数计算。

### 4.2 “属于谁 / 哪个阶段”优先于“叫什么”

当前最先固定的是：

```text
S → O → D → E
```

不仅要问变量属于哪个盒子，还要问：**它在什么时候才有资格出现？**

第二层 schema 可以后续逐步形成，但不能破坏四类底层坐标和阶段顺序。

### 4.3 不强迫线性加权

后续函数可以包含：

- 阈值；
- 非线性；
- 最佳区间；
- 不可补偿项；
- 交互项；
- 滞后与路径依赖；
- Bayesian updating；
- 关系历史依赖。

因此当前框架只固定“变量来自哪里、什么时候出现”，不预设最终数学形式。

### 4.4 不用缺失值伪造尚未发生的阶段

如果两个人尚未真正互动：

```text
D = unknown / not-yet-formed
```

而不是根据资料脑补一个 `D`。

如果关系尚未进入需要考察现实嵌入的阶段：

```text
E-stage = not-yet-invoked
```

而不是为了让四元组完整而提前做婚姻尽调。

## 5. 结构图

```text
S_t · 主体 / 我
      │
      │ 遇见、观察
      ▼
O_t · 客体 / 她
      │
      │ 若发生足够互动
      ▼
D_t · 二人 / 我们
      │
      │ 若关系形成并进入持续现实考察
      ▼
E_t · 环境 / 我们进入世界
```

相应的状态空间逐层扩张：

```text
S
↓
(S, O)
↓
(S, O, D)
↓
(S, O, D, E)
```

而 `t` 始终只是状态变化的索引，`ρ` 始终只是当前拿什么尺子量。

## 6. 当前研究边界

v0.1.1 冻结：

```text
四类底层变量：S / O / D / E
固定展开顺序：S → O → D → E
阶段状态：X¹ → X² → X³ → X⁴
时间索引：t
评价镜头：ρ
统一函数族：F_k
```

暂不冻结：

- 各类变量的完整二级 taxonomy；
- 各函数的数学形式；
- 各变量权重；
- 总体“喜欢”函数；
- 婚姻或关系的统一总分；
- `D` 形成与 `E-stage` 启动的具体阈值。

下一步应从最基础、相对可观测的函数开始逐个研究，例如：

1. `F_visual`：视觉审美 / 视觉吸引；
2. `F_sexual`：性吸引；
3. `F_interaction`：互动愉悦；
4. `F_chemistry`：化学反应；
5. `F_trust`：信任；
6. `F_role`：角色适配；
7. `F_stability`：关系稳定。

目标不是尽快得到一个万能答案，而是建立一套即使主体、客体、关系阶段和社会环境都变化，也无需推翻的基础坐标系。
