# X06 — Irreducible pair-level latent state stress test v0.1

Status: RESEARCH_CANDIDATE / NOT CANONICAL.

Architect finding: current evidence does not justify adding a new undirected pair-level latent primitive.

Why:
- Dyadic methods can recover pair-specific interaction structure that is not reducible to person-level traits alone.
- But that does not imply the ontology needs one shared scalar state. Existing LHRM already has directional relation states, shared pair facts, Belief, Action/Event, and derived mutuality/asymmetry.
- A pair-specific latent may be a measurement-model component or derived readout without becoming a primitive world-state coordinate.

Evidence anchors:
- Gin et al., A Dyadic IRT Model (arXiv:1906.01100): pair-specific interaction latent variables can add information beyond actor/partner properties.
- Cropley & Reid 2008, DOI 10.1177/1066480708322806: latent dyadic/cross-individual modeling can represent couple interdependence.
- Shared-reality work shows meaningful perceived commonality between partners, but it remains a construct requiring explicit measurement rather than proof of one universal pair latent.

Promotion gate for any future pair-level primitive:
1. repeated mapping failures under Agent + directed Relationship + shared facts + Belief + Action/Event;
2. semantic identity not reducible to averaging, agreement, reciprocity, mutuality, or correlation of directed states;
3. independent indicators that identify the pair component;
4. incremental explanatory/predictive value beyond the compositional model;
5. cross-context stability and measurement validity;
6. explicit update semantics and Unknown handling.

Until all six are met, use DERIVE/measurement-model representation rather than ontology expansion.

Verdict: HOLD_NEW_PAIR_LATENT_PRIMITIVE.
