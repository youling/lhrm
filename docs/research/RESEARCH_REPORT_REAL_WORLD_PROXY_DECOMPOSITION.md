## 0. Acknowledged Rulings

本报告遵守 #2 的两项现行裁定：其一，LHRM 研究对象为一般人际关系系统，性别/生理性征/亲缘是可能相关的属性而非入口假设，参数须通过 cross-sex / same-sex / kin / non-kin / stranger / established-relationship 反例测试；其二，研究域为 Human–Human Dyad，外部扩展只作为 context，参数须标注 `mechanism | primitive_state | observable_proxy | derived_outcome | role_constraint` 五分类，并以"最小充分性"审查——已知候选状态后，更底层机制不再提供独立信息时，低层项留在 mechanism/evidence 层。

## 1. 执行摘要

**核心结论一：绝大多数现实高频词是复合代理，直接平级使用必然双重计数。** 从社会统计与日常语汇中拆出的 126 个高频词中，仅少数（日历年龄、收入、婚姻法律状态、血缘）是可直接观测的原子量；绝大多数同时代理多个不可约构念。「肯花钱」「陪伴」「颜值」这类词被统计口径、相亲文案和关系科学文献反复使用的强度，与其语义的歧义度成正比。

**核心结论二：关系持久性、满意度、强度、合法状态、道德评价、社会认可、福利是七个互不还原的轴。** Joel 等（2020）43 个纵向数据集结果可直接支撑其中三个分离：actor 自报的关系特质（感知承诺、赏识、性满意、感知对方满意、冲突）可解释同期满意度约 45%，但关系满意度随时间的**变化几乎不可预测**（任一模型 <5%），即 satisfaction 与 persistence 解耦；人口学/客观状态变量（同居、婚姻、是否有孩子）几乎无预测力，即合法状态、结构角色与体验强度解耦。

**核心结论三：统计数据库大量变量只适合做 prior/base-rate，不能冒充关系 primitive。** 全国结婚登记对数是宏观流量，对应的是"进入合法关系的先验概率"；普查中的平均初婚年龄校准的是 life stage 与婚姻市场 base rate，不是任何 dyad 状态；收入、教育、户籍等社会经济变量是 Agent 级资源/身份约束，对 dyad 内部状态基本是 conditionally independent。

**核心结论四：极端案例不需要新增一级类别。** 38 个 adversarial cases（含同性、亲子、手足、极端依赖、共同违法、欺骗、复合循环、极端年龄/财富差、多人关系、扶养义务冲突）全部可用 Agent / Relationship / Environment / Belief + Action/Event 表达，无一处需要临时发明一级关系类别；需要的只是把"关系是否合法/是否被认可"从"关系是否强"里拆出去。

**核心结论五：重复计数的最高危路径集中在四个族。** 资源族（收入/资产/消费/家庭背景/职业）、投入族（陪伴/可得性/responsiveness/照顾/家务/时间）、品质族（负责任/承诺/忠诚），以及外观族（颜值/年轻感/年龄/健康）。在四关审查（语义独立、反例解耦、条件增量、干预独立性）下，多数合并建议发生在族内而非跨族。

## 2. 方法与分类体系

### 2.1 样本范围

- 中国及可比较国家/地区的婚姻、离婚、人口、家庭、收入、教育、住房、迁移、就业公开统计（第三节映射表）；
- 婚姻/家庭/关系研究常用量表与 longitudinal dataset（CFPS、CHARLS、CGSS、Add Health、NSFG、NLSY、HRS、PSID、ESS、WVS）；
- 新闻、判例、人物报道与论坛叙事，仅作覆盖度与反例测试来源，不据此估计概率。

### 2.2 每条目统一字段

| 字段 | 含义 |
|---|---|
| 高频词 | 现实自然语言/统计口径中的表面词 |
| 类型 | `O`＝直接观测(direct observation)；`P`＝代理(proxy)；`L`＝潜变量(latent)；`D`＝派生判断(derived judgment)；`R`＝角色依赖约束(role-dependent constraint)；附五分类注解 mechanism/primitive_state/observable_proxy/derived_outcome/role_constraint |
| 映射 | 可能对应哪些更基础构念（层：Agent/Relationship/Environment/Belief） |
| 重复计数风险 | 与此 proxy 并存时最容易被重复计算的构念 |
| 解耦反例 | 使该 proxy 与常见解释脱钩的最小现实反例 |

### 2.3 证据分级

`E1` established construct（量表与多研究复现）；`E2` plausible proxy（单点/理论推演）；`E3` product heuristic（产品/文案惯例）；`E4` anecdotal pattern（个案/论坛）；`EU` Unknown。统计变量一律只校准先验或 base rate。

### 2.4 不进入 canonical 的纪律

- 不因为"听起来更底层"就自动升级；低层机制只在显著提升语义独立性、预测充分性或可操作测量时才进入 primitive 候选；
- 不因关系类型造专用参数；同一组参数需能表达亲子、手足、朋友、同事、前任、配偶、第三者、陌生关系；
- 法律/道德/社会规范状态与强度状态分开建模，不互相充当取值。

## 3. Proxy Decomposition Dictionary

共 **126 条**，按九个域编号 W01–W126。类型栏：`O`=direct observation，`P`=proxy，`L`=latent construct，`D`=derived judgment，`R`=role-dependent constraint；括号内为五分类注解（mechanism / primitive_state / observable_proxy / derived_outcome / role_constraint）。`mixed` 表示该词在语用中同时承担数类。

| W126 | 沉没成本/退出障碍 | D (derived_outcome) | 分手的法律/经济/社会/心理摩擦 | 承诺、爱、依赖 | 因分产繁琐维持的婚姻最稳定且最痛苦：持久≠满意 |

## 4. Adversarial Cases（38 例）

| ADV13 | 丧偶老夫妻再婚后按遗嘱把财产尽数留给亲生子，二婚婚龄 15 年 | 继父母角色、财产安排与情感并存 | 财产契约=role/legal；情感 bond 独立；不冲突 |

| ADV16 | 知情同意的开放式关系：主伴侣 12 年稳定，双方各有多年固定外伴，形成家庭聚会 | 排他契约是可配置 role_constraint，非强度默认值 | exclusivity=契约条款可开关；commitment/trust 正常表达 |

| ADV19 | 确诊绝症后，伴侣不离不弃三年，自述"从没这么近过" | 疾病事件提升联结；危机≠日常满意 | Event/环境冲击与连接强度、满意度独立建模 |
| ADV20 | 双高情绪化异性 twin 型伴侣：每周大吵两次+反复热恋+和好，外人看"不正常"他们对这种高激活很满足 | 冲突频率与满意显著解耦，激活水平有个人差异 | 冲突频率、满意度、追求"平静"的评价分开；perceiver 维度被保留 |
| ADV21 | 广场舞认识的六旬男女同居不登记，各自孩子反对经济完全独立 | 老年伴侣、同居不婚、子女反对 | 同上，多加 life stage（Agent）与 legal status 字段 |
| ADV22 | 从未线下见面的网游婚恋"网恋"6 年，双方在不同国家 | 亲密可在无物理接触下建立；互动质量≠性/在场 | 互动依赖文本/语音的 D 层；物理在场不设默认值 |
| ADV23 | 国外执行任务的军人用固定频率密文联络家人 12 年 | 可预测的非连续联络仍构成高可得性 | availability 定义为预期响应模式而非频率，可表达 |
| ADV24 | 前妻与现任丈夫、前夫三方共同育儿周末，孩子周全 | 前任卷入与再婚家庭结构的正常化 | 多边 Relationship 边+共享育儿 role_constraint，可表达 |
| ADV25 | 女方 PhD 家暴订婚对象被判刑，其余维度"都很好" | 高学历/高功能与暴力并存：属性≠关系行为 | Agent 属性与 Relationship 行为分开记录即可，无需"高功能暴力"专门类 |
| ADV26 | 养子成年后与养母同居并继承遗产，遭村邻非议 | 亲缘的法律/血缘/养育三属性分开 | kinship 的合法血亲、收养、姻亲分量建档，行为事件独立表达 |
| ADV27 | 成年儿子婚后仍依赖父母打款、父母住其家并纳贡，称"感恩" | 成年依赖与反向赡养并存的结构 | value 与 dependence 两轴；wealth transfer 事件流可追溯 |
| ADV28 | 长期恐惧关系受虐者用"他平时对我很好"总结 20 年婚姻 | 受害与既往温暖样本共存，需时间序列样本分类 | 虐待事件计入负样本，温暖计入正样本；不合并为一个"关系质量"数 |
| ADV29 | 联邦政客式夫妻：公开互相称颂、私下分居 5 年维持形象与席位 | 公开表演/形象投资与私密状态分离 | 表演性表达=对外 Action；私密 Relationship 状态=内部状态；分离不冲突 |
| ADV30 | 青梅竹马分别 20 年各自婚后又各自离婚，最终复合并共度晚年 | established-relationship 起点、中途解耦后复合 | 时间线分段表达，每段独立状态；复合=重新进入新关系边 |
| ADV31 | 婚内无爱但为学区房、户口、医保便利共同生活至孩子高考 | 结构激励维持结构但零质量 | legal/经济 structure 与 satisfaction 分离表达，正好支持"持久≠满意" |
| ADV32 | 跨国婚姻中配偶靠绿卡维持关系直到入籍后 18 个月即离 | 入籍事件的制度性锁定与关系内容解耦 | Event（入籍）+ 关系解除状（empty bond）可表达 |
| ADV33 | 高僧与多年信徒的"精神伴侣"，承诺"以师徒相称终身陪伴"，社会高度认可 | 非浪漫非性的深度承诺关系；社会认可高 | 承诺可不含性/浪漫；关系可以让定义为 spiritual bond |
| ADV34 | 富商死前将全部遗产留给无血缘的女管家（相伴 30 年） | 服务+陪伴+长期结构 vs 法定继承人 | 服务关系、亲缘、财产意愿三轴分离即可表达，不需要"管家关系"类 |
| ADV35 | 双高收入医生夫妻五年前后各三次异地轮值，合力买房生娃但每周只见两天，自认"这是人生选择" | 高投入事业+育儿+低共处时长并存且自洽 | 陪伴时长低、工具性支持高、投入高可同存；评价主体承认偏好 |
| ADV36 | 某男与伴侣在伴侣绝症末期举行婚礼求婚当晚安排遗嘱 | 求婚：仪式化 Action；遗嘱：法律 Action；两者不同轴 | 仪式事件与法律结构分开，不需要"临终婚姻"新类 |
| ADV37 | 无共同语言的中日夫妻用翻译软件交流十年并抚养两孩 | 语言不通但支持与承诺可成立 | 沟通媒介与理解质量解耦；需与"沟通质量"分开的媒介层 |
| ADV38 | 一夜情转化为十年稳定伴侣，而"恋爱 3 年后求婚"的另一对在 4 年处分手 | 起点强度与终点持久不绑定，时间尺度敏感 | 起点类型只是 prior；转移概率需数据校准，结构上无需新类别 |

**Cases 的共性结论：** 38 例无一需要新增一级关系类别。所需要的全部表达能力来自：多边关系边（多对象、前任、亲属、契约）、Agent 属性与 Relationship/行为/事件分离、Belief（欺骗/理想化/表演）与事实分离、legal/social/moral 三类外部评价轴与 dyad 强度轴分离、以及时间序列（cycling、危机、复合）。这与 Ruling 5565245810 的最小充分性判据一致。

| Karney & Bradbury VSA / family stress 研究 | 经济压力、婚姻满意度、离婚概率 | 压力—适应—满意度路径（E1） | meta 关联 ≠ 个体 dyad 确定性 |
| 中国地区婚俗/彩礼调研与征婚文案（地方/媒体） | 彩礼区间、随礼、相亲资料用词频率 | 婚恋市场交换模式与压缩语用 prior（E3） | 文案规律是 market heuristic，不是关系事实 |

**一句话提醒：** 中间三块（民政、统计、普查）全部只进 prior/base-rate；只有带 dyad 编码的纵向调查（CFPS、Add Health、HRS、PSID 及实验室编码）才有条件校准 primitive，且必须由前文"五分类"决定哪些进 primitive、哪些留在 mechanism。

**解读：** 双计数最剧烈区集中在三处——颜值/健康×爱/亲密、财富/资源×投入/陪伴、爱/亲密×品质/承诺。这三处恰恰是"看起来是描述关系强度、实际把外显资源当情感信号"的通道。其次值得注意的是合法/结构、道德/规范、社会/认可三个外部评价轴之间的高交织：现实中"合法了=道德=被认可"几乎是默认外推，模型必须显式拆开，否则 ADV29（政客夫妻）与 ADV31（学区房婚姻）这类 case 无法被无偏表达。

## 8. 低冗余四关审查（方法 + 两例演示）

四种可执行、可复现的审查关卡。本报告不真正跑全量数据（本轮明确不做），但给出判定规程与手做演示。

1. **语义独立关**：给两个候选参数分别给出不存在"第三方语义重述"的解释。若一方定义必然引用另一方，则 fail。
2. **反例解耦关**：构造一个现实可例，使一个参数在另一个参数取值不变时自由变动。能构成解耦反例者通过。
3. **条件增量关**：在控制更基础候选后检查剩余判别力（可形式化为 `P(y|a, b) = P(y|a)` 条件独立筛查；后续用 SEM/partial correlation 检验）。
4. **干预独立关**：按潜在结果框架，若推进一个机制（do() 干预，如提升 generosity 供给）不能单独改变另一个参数（如 spending）的分布，说明后者是复合观测不是 primitive。

**演示 A：`肯花钱（W79）`**

- 语义独立：语义上"资源充裕（W17）""慷慨倾向""求偶信号投入""冲动消费"四条路径描述不同对象。
- 反例：富人对关系一毛不拔（资源↑、行为↓）；穷人为关系节衣缩食（资源↓、行为↑）——解耦成功。
- 条件增量：已知 income、generosity trait、courtship intent 后，spending 作为单独变量不再带独立信息 → **fail，降级为 observable_proxy**。
- 干预独立：仅 do(慷慨提高) 就能大幅改变 spending 分布 → spending 不是独立 primitive，而是多个机制的合取输出。
- **结论：`肯花钱` 保留为观测指标；primitive 候选是被其代理的资源充裕度、慷慨、求偶信号、冲动。**

**演示 B：`陪伴（W33/W34/W35）`**

- 语义独立：三个词分别指共处时间、可联络性、按对方需要回应。可区分。
- 反例：同室异梦（时长↑回应↓）与异地秒回（时长↓回应↑）双向解耦。
- 条件增量：控制 responsiveness 后 co-presence 对满意几乎无增量（Joel 2020 中结构/时间类客观变量弱预测）→ 保留 responsiveness、availability 条件，co-presence 降为上下文观测。
- 干预独立：do(增加物理共处) 不必然改变 responsiveness → 物理时长非 primitive。
- **结论：`陪伴` 拆为 responsiveness(primitive 候选) + availability(上下文) + co-presence(context 观测)，三者不再平级。**

**演示 C：`颜值（W09）`（简版）**

- 反例：高颜值高自恋 vs 普通颜值高友善，吸引力与亲社会行为解耦。
- 条件增量：Joel 2020 显示人口学/外形客观量对满意弱预测 → 颜值作为 Agent 属性与刺激量，不进入 Relationship primitive。
- **结论：颜值是 Agent 属性 + perceiver 偏好函数输入，不是 dyad 状态。**

### §8.5 数据验证方法（未来可执行，本轮未跑）

- **因子分析**：对映射表中 dyad 编码库（CFPS 自报、Add Health、Lab 编码）做 EFA 提取公因子，检查 §6 高危族是否坍缩。
- **条件独立性**：SEM/局部独立检验 `P(satisfaction | actor-relationship vars, demographics) = P(satisfaction | actor-relationship vars)`（Joel 2020 已给方向性证据）。
- **干预/拟实验**：事件研究（如 COVID 同居冲击、离婚冷静期的 policy change）作为 do() 近似。
- **反例数据库化**：将 §4 的 38 例转成可执行的覆盖度测试集，每次 ontology 修改回归一次。

## 9. "最小充分状态变量"的压力测试结论

综合 126 条拆解、38 例对抗、四关与矩阵，对"最小充分性"给出如下候选结论（**仅候选，不冻结；交由 #2 联合 Architect 融合**）：

1. **四处核心 primitive 族足够覆盖全部案例**：①资源与权力结构（谁依赖谁、谁控制什么、可再分配资源流，含双方互依与投资）；②回应与情感调解（responsiveness、felt security、信任、风险调节，adult attachment 维度作为 Agent 供给侧）；③契约期望与背叛（期望 CL、承诺 dual components、排他契约、意图性欺骗）；④冲击与事件（生命事件、危机、结构性制度约束）→ 覆盖 38/38 examples。

2. **必须与 dyad 强度并存的五个独立轴**：satisfaction、strength/bond、persistence、legal status、social approval（另加 welfare 作个体福利轴）。任何把五轴合并成"关系质量单分"的门面（LoveScore）在 ADV29/31/38 类型的案例上必然失真。

3. **Agent 级供给侧参数**（健康池、资源池、时间束、人格/依恋调节、价值观矩阵、偏好/取向）是 dyad 的分布输入而非 dyad 状态；统计数据库的大部分工作是把它们的 prior/base-rate 学好，而不是把它们当关系 primitive。

4. **Belief 层不可省**：comparison level、理想化、许诺可信度、欺骗信息状态、对合法/道德/命运的信念，是 ADV7/8/11/18/22 等多数反例的必要载体。缺 Belief 层时这些 case 会产生"模型无处可放"的伪漏项。

5. **过度拆分的真实成本**：若不按 §7.2 降级，候选参数会膨胀到 126+ 且在高危族内发生系统性双记；风险最高的三个族（资源×投入×承诺）应先于其它做因子分析。**建议:Architect 在 #2 融合时把 §7.1 并入、§7.2 降级、并以 §6 矩阵为双记审计首序。**
