# LHRM

**Li-Hong Relationship Model / 礼宏关系模型**

LHRM 是一个用于研究、表达与仿真人际/亲密关系的开放研究项目。当前目标不是制造单一的“恋爱打分器”，而是逐步建立一套：

- 足够凝练，能覆盖复杂真实世界；
- 支持部分信息、未知信息与动态更新；
- 能区分主体、客体、关系、环境、认知与角色；
- 能吸收关系科学、社会统计、游戏/婚恋产品建模经验；
- 最终可用于概率预测与关系微观仿真；
- 明确区分研究假说、经验事实、参数估计与软件实现。

## 治理

LHRM 的全局 Agent 治理遵循 `youling/ai-use` 当前规范；Git/GitHub 是 durable truth。研究结论不得强于证据，未经数据校准的数学结构不得表述为已验证预测模型。
